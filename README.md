# Detecting seizures with wearables

A 45-minute in-browser Python workshop for high school students. Students count heartbeats in simulated smartwatch (PPG) data, compare exercise with seizures, and build a simple seizure alarm.

- `index.html`: landing page; preloads the Python engine
- `workshop.html`: the workshop itself (Python runs in the browser via [Pyodide](https://pyodide.org) from jsDelivr)

All data is simulated. No installs, accounts or servers needed: any static host works.
